# Restaurant Management System

A comprehensive web-based restaurant management system built with HTML, CSS, and JavaScript. This system provides a complete solution for managing restaurant operations including menu management, order processing, billing, reservations, inventory, staff management, and reporting.

## Features

### Core Modules
- **Dashboard** - Central overview with key metrics, charts, and real-time statistics
- **Menu Management** - Full CRUD operations for menu items with categories, pricing, and descriptions
- **Order Management** - Create, update, and track orders with status management
- **Billing System** - Generate bills, apply discounts, split bills, and process payments
- **Reservations** - Manage table bookings with date/time selection and customer details
- **Customer Management** - Track customer information, order history, and preferences
- **Staff Management** - Employee records, roles, shifts, and performance tracking
- **Inventory Control** - Track stock levels, suppliers, and purchase orders
- **Supplier Management** - Manage vendor information and supply chain
- **Table Management** - Table layout, capacity, and availability tracking
- **Reports & Analytics** - Generate sales reports, popularity analysis, and financial summaries
- **User Profile & Settings** - Personalization and system configuration

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Data Storage:** LocalStorage with sample data seed
- **Charts:** Chart.js for data visualization
- **Icons:** Font Awesome icons
- **Styling:** Custom responsive CSS with modern design

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/restaurant-management-system.git
   ```

2. **Open the application**
   - Open `index.html` in any modern web browser
   - Login credentials are pre-configured in the sample data

3. **Explore the system**
   - Navigate through the sidebar menu
   - Add, edit, and manage restaurant data
   - Generate reports and analyze performance

## Usage

The system comes pre-loaded with sample data for demonstration purposes. You can:

- Add new menu items with categories and pricing
- Create and manage customer orders
- Process payments and generate bills
- Track inventory levels and supplier information
- Manage staff schedules and performance
- View comprehensive reports and analytics
